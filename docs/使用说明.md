# Codex 监控小鱼 · Skill 分享版

把整个压缩包发给朋友即可。它会让 Codex 在朋友的电脑上生成项目 Token 看板：黑红界面、左侧H 品牌标识、右侧个人头像、亿/整数切换、新增任务自动发现、子任务合计和 CSV 导出。

## 给朋友的安装方法

1. 解压压缩包，将里面完整的 `codex-token-monitor` 文件夹放到个人 Skill 目录：Windows 是 `%USERPROFILE%\.agents\skills\`，macOS/Linux 是 `~/.agents/skills/`。没有目录就创建。最终应能找到 `.agents/skills/codex-token-monitor/SKILL.md`。只想给某项目使用，也可放在该项目的 `.agents/skills/` 中。
2. 在 Codex 中打开想统计的项目。若技能没有出现，重启 Codex。上述目录和发现方式参照 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。这是可手动放入本地目录的 Skill 包，无需发布到商店。
3. 给 Codex 发这句话：

   **使用 $codex-token-monitor，帮我为当前项目生成 Codex 监控小鱼，并打开页面。**

也可以直接把解压后的文件夹位置告诉 Codex，并说“请读取其中的 SKILL.md，按它为当前项目建立监控器”。

## 使用页面

- 左侧红底白 H 是本产品的品牌标识；右侧默认是通用用户图标，点击它可上传自己的 JPG、PNG 或 WebP，最大 2 MB。头像保存在当前浏览器，换浏览器或换端口需要重新选择。
- 支持“亿”和完整整数单位；鼠标悬停可看精确数值。导出的 CSV 始终保留整数。
- 默认每 10 秒读取一次本机记录。新增同目录任务会自动加入；归档任务保留历史用量。可暂停自动刷新、立即刷新或切换是否计入子任务。
- 再次启动：Windows 双击生成的监控目录里的 `打开监控器.cmd`；macOS/Linux 在该目录运行 `python3 launch.py`。也可直接请 Codex“打开已有的 Codex 监控小鱼”。

## 运行要求与范围

需要在本机使用过 Codex，并能读取其本地数据；需要 Python 3.10 或更高版本。没有运行时可以请 Codex 协助查找已有运行时，或按提示安装。程序只使用 Python 标准库，不需要购买 API Key 或安装第三方 Python 包。

默认读取 `CODEX_HOME`，未设置则读取当前用户的 `~/.codex`。项目目录和端口在首次生成时配置，不包含发送者电脑的路径。网页只在本机 `127.0.0.1` 提供服务，没有云端上传或开机启动。已有端口被占用时可以另选端口。

当前解析器适配含 `state_5.sqlite` 及逐次 `token_usage_record` 的本地记录。如果 Codex 版本结构不同、只有旧版累计快照或日志已被清理，会提示不支持或数据不完整。它只统计能在本机读到的记录，无法自动补齐其他设备或云端任务。

这反映项目的历史 Token 处理量，不能换算订阅“剩余百分比”或人民币账单，也不包含图片/视频等外部工具费用。缓存输入与推理输出已经包含在输入、输出中，不重复累加。看板自动刷新本身不调用模型；请 Codex 创建、修改或使用 Skill 会正常产生任务用量。

分享包只包含 Skill、程序和界面资源，以及经作者指定保留的 H 品牌图。没有作者的任务记录、数据库、导出表格、账号信息或个人头像缓存。使用后生成的 `config.json`、快照、CSV 和截图属于使用者自己的数据，不要将整个运行目录当作原始分享包转发。

Windows 已实际启动和浏览器验证；macOS/Linux 的路径处理通过合成数据测试，尚未在实机验证。
