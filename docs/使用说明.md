# Codex 监控小鱼

## 发给朋友的一段话

让朋友把这段话发给自己电脑上的 Codex：

```text
请从 https://github.com/huangxin-design/codex-monitor-fish 安装 skills/codex-token-monitor 这个 Skill，安装后立即读取它的 SKILL.md 并继续执行，打开项目选择网页，我选好项目后就开始监控 Token。请复用本机或 Codex 提供的 Python 运行时，帮我完成安装和启动，不要让我手动下载、输入命令或安装 EXE。
```

Codex 会先安装完整 Skill，再在同一次对话里启动服务并打开网页。网页出现后，**选择项目 → 点击开始监控**。安装需要能访问仓库；运行需要这台电脑上的 Codex 使用记录及可用的 Python 3.10+，由 Codex 查找系统或宿主提供的运行时。

你不需要手动下载程序、解压文件、输入命令或安装 EXE。若 Codex 只能访问普通云端聊天环境，无法读取本机记录；如果仓库不可访问或缺少运行时，它应说明实际原因，不能只给下载页就说完成了。

## 下次打开

告诉 Codex：

```text
使用 $codex-token-monitor，打开监控网页。
```

会恢复上次选择的项目。想换一个项目时，在网页点 **切换项目**，或告诉 Codex“打开 Codex 监控小鱼的项目选择页”。

## 在网页里使用

- **切换项目**：重新选择要统计的项目。
- **退出监控**：停止后台读取；下次让 Codex 打开即可。
- **亿 / 完整整数**：调整数字显示单位；CSV 始终导出整数。
- **右侧头像**：点击上传自己的 JPG、PNG 或 WebP，最大 2 MB。
- **暂停刷新 / 立即刷新**：控制刷新节奏；默认每 10 秒更新。

如果没有找到项目，先在本机 Codex 中运行过一次任务，再点击 **重新查找**。数据目录迁移过时，可展开 **没有找到项目？** 指定实际的使用记录文件夹。

首次读取大量历史记录可能需要几十秒或更长；页面会显示进度条、已处理记录份数与当前任务。**读完一个任务就显示一个**，这时数字标为“当前已读用量”；读取结束后再显示最终结果。普通刷新保留上次统计，切换项目会清除旧项目数字。

进度按记录文件处理情况计算，大文件会继续更新文件内的读取进度；它不是剩余时间预估。只有服务确认本轮读取结束后才显示 100%。

旧版或缺失日志不会让整个列表失败。受影响任务会标注原因；“≥”表示已确认的用量下限，“—”表示无法准确统计，不代表没有消耗。部分结果或存在无法确认的记录时，CSV 导出暂不可用。

项目选择保存在当前用户的本机 Skill 运行目录；头像保存在当前浏览器。换浏览器或端口后，头像需要重新选择。Skill 与原 Windows EXE 各自保留设置，互不覆盖。

## 数字表示什么

这是本机记录可见的历史 Token 处理量，不是账户剩余额度或收费账单。缓存已经包含在输入中，推理已经包含在输出中，不重复加总。其他设备、云端任务和图片/视频工具费用不在统计范围。

解析器需要逐次 `token_usage_record` 与对应任务索引。版本结构不兼容或日志不完整时会提示原因。程序只在本机读取记录，不上传任务或头像；自动刷新不会调用模型。

## 人民币估算与额度重置

总 Token 旁边直接显示人民币成本，采用自定 20x 方案：每周 20 亿 Token × 4 周，共 80 亿 Token，费用 200 美元。每亿 Token 分摊 2.5 美元；默认汇率 7.00 时约 ¥17.50。公式及汇率设置放在“统计说明”里。这个总量是工具的估算口径，不是官方固定配额；金额是订阅费用分摊，不是新增扣费。缺失日志只计算已确认部分。

顶部显示“预计下一轮重置”，以 Codex 周额度的官方时间计算倒计时。点击旁边的刷新按钮尝试重新读取；CLI 与桌面登录可能不同，失败时可让 Codex 更新账户快照。超过 15 分钟或时间已过时，页面提示获取最新时间。日期使用浏览器本地时区，程序不会使用重置券。
