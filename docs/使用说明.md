# Codex 监控小鱼

## 推荐：给 Codex 一句话

把下面这句话发给电脑上的 Codex：

```text
请按照 https://github.com/huangxin-design/codex-monitor-fish 的 INSTALL.md，自动安装 Codex 监控小鱼并打开项目选择网页，我选好项目后就开始监控 Token。
```

等待 Codex 安装并打开网页，选一个项目，点击 **开始监控**。以后告诉 Codex“打开 Codex 监控小鱼”即可，项目选择会保留。目前自动安装适用于 Windows 10/11 64 位。

## 也可以下载后双击

1. [下载 Windows 免安装启动版](https://github.com/huangxin-design/codex-monitor-fish/releases/latest/download/CodexMonitorFish-Windows.exe)。
2. 双击打开，网页会自动弹出。
3. 选择要统计的项目，点击 **开始监控**。以后会记住你的选择。

无需安装 Python、复制 Skill 文件夹或输入命令。适用于 Windows 10/11 64 位，需要本机已有 Codex 使用记录。当前 EXE 未进行代码签名，Windows 可能提示无法验证发布者。

## 在网页里使用

- **切换项目**：重新选择要统计的项目。
- **退出监控**：停止后台读取；下次双击程序即可重新打开。
- **亿 / 完整整数**：调整数字显示单位；CSV 始终导出整数。
- **右侧头像**：点击上传自己的 JPG、PNG 或 WebP，最大 2 MB。
- **暂停刷新 / 立即刷新**：控制刷新节奏；默认每 10 秒更新。

如果没有找到项目，先在本机 Codex 中运行过一次任务，再点击 **重新查找**。数据目录迁移过时，可展开 **没有找到项目？** 指定实际的使用记录文件夹。

项目选择保存在当前用户的本机应用目录；头像保存在当前浏览器。换浏览器或端口后，头像需要重新选择。

## 数字表示什么

这是本机记录可见的历史 Token 处理量，不是账户剩余额度或收费账单。缓存已经包含在输入中，推理已经包含在输出中，不重复加总。其他设备、云端任务和图片/视频工具费用不在统计范围。

解析器需要逐次 `token_usage_record` 与对应任务索引。版本结构不兼容或日志不完整时会提示原因。程序只在本机读取记录，不上传任务或头像；自动刷新不会调用模型。
