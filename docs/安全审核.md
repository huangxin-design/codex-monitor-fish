## 运行与数据边界

| 发现的问题 | 修复与复测结果 |
| --- | --- |
| 外部网页可借自定义目录 GET 触发文件路径探测 | 自定义目录扫描改为要求同源及随机令牌的 POST；GET 不接受目录参数；UNC、设备路径在访问前拒绝。使用拦截测试，未实际访问外部共享。 |
| 被改写的日志索引可以指向所选数据目录之外 | 日志只从所选 Codex 数据目录读取；旧位置迁移后仅在该目录内寻找对应日志。越界记录显示不完整提示。 |
| 异常模型字段可导致用量请求失败 | 校验字段类型，跳过坏字段并提示，保留有效用量。 |
| CSV 中带前导空白的公式文本与任务编号未转义 | 全部名称和编号字段统一转义，Token 数值仍为完整整数。复测检查导出内容，未在表格软件中执行公式。 |
| 损坏的实例元数据或非对象健康检查结果可导致启动失败 | 验证类型、应用标识、实例、进程与本地地址；异常数据安全返回未就绪。 |
| 极深的 JSON 请求产生未处理异常 | 返回明确的 400 响应；请求体有长度和读取超时限制。 |

原始六项复现均已通过独立复核。拒绝错误 Host、Origin、令牌和目录穿越的检查，以及正常项目选择、切换和统计回归均通过。

- 实际 Windows EXE 在独立目录、空 Python PATH 下验证首次选择、准确合计、重复启动复用、重启恢复选择与正常退出。

测试命令见 README 与仓库 CI。发布后的下载文件与自动安装结果需以该版本实际发布检查为准，不把模拟安装测试当作真实下载测试。

## 限制

- 当前 EXE 未做代码签名；SHA-256 只检查与同一发布来源的一致性，不能证明发布账号或本机未被入侵。
- 服务限定本机访问，不提供多用户身份认证；拥有同一 Windows 用户权限的程序不在隔离边界内。
- SQLite 只读连接在实时 WAL 模式下仍可能创建 `-shm` 共享内存辅助文件。测试确认源数据库与会话日志内容未被修改，不承诺目录内绝对没有辅助文件写入。
- 本机 Windows 无创建符号链接权限，对应回归测试跳过；支持该功能的平台通过 CI 继续执行。没有实测 SMB 通信、macOS/Linux 桌面浏览器或恶意软件防护兼容性。
